Daijobu Island.
dynamic island buat Windows 11, rasa kaset.

Overlay pill di atas layar yang nampilin musik, OSD volume, timer, notif, vitals sistem, dan tools bersih-bersih ala Mole. Dibikin full Rust, render pakai Skia (D3D12), dan langsung ke Win32 native, tanpa winit atau webview. Bentuknya modern (morph pakai spring, crisp), tapi teksturnya lofi (grain, dither, status playback, angka dot-matrix).

01 · arah

Prinsip

Native beneran

Window Win32 mentah dan DirectComposition. Idle ≈ 0% CPU karena nunggu di GetMessage. UI tanpa runtime web. Music juga native: Windows GSMTC, tanpa embedded browser.

Modern = motion

Lebar, tinggi, dan radius morph pakai spring yang bisa di-interrupt. Konten crossfade dengan blur dan scale 0.94 → 1.

Lofi = tekstur

Lofi-nya dari tekstur, bukan dari layout yang rame: grain 4–6% (re-seed 18 fps), dither Bayer di gradient, label mono kapital, indikator playback statis.

Fungsional

Bukan pajangan. Setiap state harus ngejawab sesuatu: lagi muter apa, volume berapa, PC sehat gak, disk bisa dikosongin berapa.

🌅 Boot Scene: abis restart, semua kebuka lagi di posisinya

  • Login, island nyala, terus scene "boot" jalan. Island nampilin progress (おはよう · 3/5) seperti di mockup
  • Per app: exe/AUMID, argumen, folder kerja, delay atau urutan (misalnya nunggu Docker dulu), dan opsi "tunggu internet"
  • Penempatan: monitor, lalu zona atau rect persis, lalu state (normal/max/min). Kalau monitornya gak ada, pindah ke primary dengan skala relatif
  • Window dicocokin pakai exe + class/title regex. Splash screen di-skip, dan posisi diulang selama ±10 detik kalau app-nya "melawan" (misalnya Chrome yang restore posisinya sendiri)
  • "Simpan susunan sekarang": snapshot semua window sekali klik, langsung jadi scene
  • Opsi auto-snapshot waktu shutdown (WM_QUERYENDSESSION), jadi kondisi terakhir yang di-restore
  • App UWP/Store dijalanin lewat IApplicationActivationManager (AUMID)

App admin tanpa prompt UAC tiap boot

UAC gak bisa (dan gak boleh) di-bypass diam-diam. Tapi Windows punya jalur resmi yang dipakai banyak app: Task Scheduler dengan "Run with highest privileges".

  • Waktu lo centang "admin" di sebuah app, UAC muncul sekali, terus island bikin task di folder \daijobu\ lewat COM ITaskService
  • Tiap boot, island cukup run task itu, dan app-nya kebuka sebagai admin tanpa prompt
  • Island sendiri gak bisa mindahin window admin (Windows memblokir app biasa ngatur window admin, namanya UIPI). Jadi task-nya ngejalanin dj-elevated.exe, helper kecil yang launch app, naruh window-nya, lalu langsung exit
  • Keamanan: path exe di-pin, dan cuma diizinkan buat exe di folder yang hanya bisa ditulis admin (Program Files). Kalau exe-nya di folder user, ada peringatan, karena siapa pun yang bisa ganti file itu bakal dapat akses admin
  • Semua task bisa dilihat dan dihapus dari settings, dan otomatis dibersihin waktu uninstall

[scene]  name = "coding"   on_boot = true   theme = "midnight"   wait_network = false

📋 Clipboard history (ala Win+V)

  • Tekan V di mockup buat coba. Isinya teks, link, warna, file, dan gambar
  • Gambar standar dari aplikasi lain: PNG atau DIB/DIBV5 yang didukung, termasuk hasil Snap. Thumbnail, ukuran dan asal app tampil di history. Preview tetap di dalam panel; gambar bisa di-paste atau di-drag keluar sebagai file. Format proprietary dilaporkan jika tidak didukung
  • Pencarian, filter All/Text/Images/Files/Pinned, pin/unpin dan delete. Alt+1‥9 untuk slot terlihat; angka biasa tetap masuk ke search. ↵ paste, ⇧↵ plain text, Ctrl+C copy
  • Hotkey default Ctrl+Alt+V, juga tersedia dari Home/tray. Win+V tetap milik Windows; Ctrl+Shift+V tetap bisa dipakai Terminal/editor
  • Paste mengembalikan fokus ke target yang dicatat saat panel dibuka, memverifikasi target, lalu mengirim Ctrl+V. Untuk Terminal island, pakai jalur paste tab tersebut. Jika target tidak valid, item tetap di-copy dan ada feedback untuk paste manual
  • Format: CF_UNICODETEXT dengan alternatif HTML Format/RTF, PNG/CF_DIBV5/CF_DIB, dan CF_HDROP copy-only. Link/warna adalah turunan teks; tidak ada fetch URL atau OCR
  • Privasi: cek ExcludeClipboardContentFromMonitorProcessing, CanIncludeInClipboardHistory=0, dan app exclusion sebelum membaca payload. Enable history saat pertama dibuka; Pause/Resume dan Clear selalu tersedia
  • SQLite + DPAPI per-user: isi, preview, path, metadata asal dan thumbnail dienkripsi sebelum ditulis. Batas 500 item biasa / 30 hari; pin bertahan setelah restart dengan maksimal 100 pin. Budget payload terenkripsi 512 MiB; item pin tidak diam-diam digusur

Motion: spring

Dari preset SwiftUI dan bentuk Dynamic Island: expand underdamped, collapse hampir critically damped. Mass = 1, ω = 2π/response, k = ω², c = 2ζω, integrasi semi-implicit Euler dengan substep 1/240 s. Kalau di-retarget di tengah jalan, kecepatannya dipertahankan.

03b · theme engine

Theme banyak, bisa switch kapan aja

Theme itu data, bukan kode: satu file .toml berisi token. Theme bawaan di-embed ke binary. Theme user ditaruh di ~/.daijobu/themes/ dan ke-reload otomatis begitu file-nya disimpan. Pas ganti theme, semua token di-interpolasi (warna di OKLab, angka secara linear) selama ±450 ms, jadi gak ada kedip.

# ~/.daijobu/themes/matcha-cafe.toml
[meta]
name    = "Matcha Café"
author  = "you"
base    = "tobacco-tape"   # inherit, override sebagian
mode    = "dark"           # dark | light

[color]
pill = "#121510"  surface1 = "#1B2019"  surface2 = "#283024"
text = "#E6E8D6"  text_dim = "#99A28A"
accent = "#A8C686"  warn = "#D9845F"  highlight = "#E8F0C8"
accent_from_cover = 0.35    # 0 = statis, 1 = full warna cover

[texture]
grain = 0.06    grain_fps = 18
dither_levels = 8   dither_cell = 2
scanlines = 0.0

[type]
title = "Geist"   label = "Geist Mono"   digits = "Doto"

[shape]
radius_scale = 1.0   hairline = 0.09   inner_glow = 0.14

[motion]
expand   = { response = 0.45, damping = 0.75 }
collapse = { response = 0.35, damping = 0.95 }

[visualizer]
style = "segment"   # segment | bar | dot | block | reel

Cara switch

  • Hotkey Ctrl+Alt+T buat cycle theme favorit, plus submenu di tray
  • Theme picker di settings, lengkap dengan preview live island beneran
  • Scroll di island sambil tahan Alt buat ganti cepat
  • Import/export: drag file .toml ke island buat install

Auto-switch (aturan)

  • Waktu: pagi pakai Paper Zine, malam Midnight Cassette, ikut sunrise/sunset
  • Per-app: YouTube Music → Sunset Poolside, game fullscreen → Amber CRT
  • Mode: pomodoro jalan → Matcha Café (grain naik pelan-pelan)
  • Ikut Windows: light/dark sistem dan accent color
  • Aturan dievaluasi dari atas ke bawah. Pilihan manual selalu menang sampai di-reset

Di Rust

  • dj-core::theme: Theme (serde), ThemeRegistry, inherit dari base, validasi
  • Validasi kontras: text vs pill minimal 4.5:1. Kalau gagal, theme ditolak dan ditandai di UI
  • Hot reload via ReadDirectoryChangesW (debounce 200 ms)
  • Renderer cuma baca ResolvedTokens, dan parameter tekstur langsung jadi uniform SkSL
  • Font di-resolve lewat Skia FontMgr. Kalau gak ada, fallback ke Geist yang di-embed

Window

  • WS_POPUP + WS_EX_NOREDIRECTIONBITMAP | TOOLWINDOW | TOPMOST | NOACTIVATE
  • Return MA_NOACTIVATE, manifest PerMonitorV2, handle WM_DPICHANGED
  • Topmost di-assert ulang lewat SetWinEventHook(EVENT_SYSTEM_FOREGROUND)
  • Click-through: rect window di-set pas seukuran pill. HTTRANSPARENT gak bisa lintas proses

Render

  • D3D12 device dan queue → direct_contexts::make_d3d
  • CreateSwapChainForComposition: 2 buffer, FLIP_SEQUENTIAL, PREMULTIPLIED
  • Swap chain dibuat fixed seukuran expanded maksimum. Pill dianimasikan di dalamnya, jadi gak ada ResizeBuffers tiap frame
  • Tiap frame clear(TRANSPARENT) → draw → flush(Present) → Present(1)
  • Kalau device hilang, rebuild context

Thread dan pacing

  • UI thread: message loop dan render. Kalau gak ada animasi, nunggu di GetMessage (0% CPU)
  • Music: bounded event-driven native MTA worker, separate bounded optional LRCLIB worker. No session polling; UI timer 250 ms hanya saat visible + playing. Art max 4 MiB, decode dimension max 4096; hasil metadata/art/lyrics stale ditolak.
  • Worker kirim hasil lewat channel + PostMessage(WM_APP) buat bangunin UI
  • Selama animasi di-pace sama Present(1). Begitu spring diam, render stop

Activity scheduler (inti UX)

Semua sumber (media, timer, OSD, notif, vitals alert, sweep) mendorong Activity dengan prioritas. Island nampilin 1 activity, atau 2 dalam mode split bubble. Activity sementara (OSD, notif) nimpa sebentar, lalu balik ke activity sebelumnya.

priority:  OSD(volume/bright) > snap thumb > notif > timer selesai > camera/mic > boot scene > dj progress > media > timer jalan > vitals alert > idle
fullscreen: semua di-hide kecuali OSD (reveal sementara), tanpa ubah z-order selama game exclusive

Shader lofi (SkSL via RuntimeEffect)

// grain: dipasang di atas pill, di-clip rrect
uniform shader src; uniform float time, strength;
float hash(float2 p){ p=fract(p*float2(123.34,456.21));
  p+=dot(p,p+45.32); return fract(p.x*p.y); }
half4 main(float2 xy){ half4 c=src.eval(xy);
  float n=hash(floor(xy)+time*37.0)-0.5;
  c.rgb += half(n*strength)*c.a; return c; }

Time di-quantize ke 18 fps biar kerasa kayak film. Ada juga Bayer 4×4 buat gradient dan art backdrop, dan scanline opsional. Semua effect di-compile sekali waktu startup.

Backdrop?

v1 pakai solid warm-black. Island asli juga hitam, dan grain plus dither lebih cocok di permukaan solid. Nanti bisa ditambah host backdrop brush (Windows.UI.Composition, window pendamping di belakang, di-clip rounded geometry) sebagai style "frosted".

Fallback: CPU raster Skia + UpdateLayeredWindow di balik trait yang sama, buat RDP/VM atau kalau D3D12 gagal.

score = 100

  − ram   (≤70: 0 · 70–88: ≤12 · >88: ≤25)
  − disk  (sys drive ≤80: 0 · 80–93: ≤10 · >93: ≤20)
  − io    (>50 MB/s linear, max 10)

  − uptime(>7d: 1 · >14d: 3)
band: 85+ daijobu · 65+ ok · 45+ hmm · <45 dame

Hasilnya muncul di compact sebagai dot berwarna. Di expanded, keluar ring dan tag penyebabnya ("CPU tinggi", "restart dulu").

Aturan safety (wajib dari hari pertama)

  • Selalu mulai dari preview / dry-run. Tombol hapus baru aktif setelah preview
  • Default ke Recycle Bin lewat IFileOperation. Hapus permanen cuma buat temp/cache
  • Path terlindungi: C:\Windows, Program Files, profile root, .ssh, .aws, Credentials, Cookies, Login Data, dan lain-lain
  • Reparse point gak pernah diikuti. Path di-resolve final, lalu dicek ulang tepat sebelum dihapus
  • Skip cache browser kalau prosesnya lagi jalan
  • Purge: target cuma dianggap artifact kalau ada Cargo.toml/pom.xml, bin/obj kalau ada .csproj, dan wajib gak ada file yang di-track git
  • Semua aksi dicatat di ~/.daijobu/operations.log, dan bisa dilihat di tab History

07 · risiko & keputusan

Yang perlu diwaspadai

Risiko teknis

  • build Skia mungkin harus build dari source (LLVM, Ninja, VS Build Tools, puluhan menit). Mitigasi: pin versi dan cache
  • topmost Rebutan z-order sama taskbar. Game exclusive-fullscreen bisa ke-minimize kalau kita utak-atik z-order pas display switch
  • resize ResizeBuffers butuh sync GPU penuh, jadi swap chain harus fixed
  • notif Butuh package identity dan cert. Toast bawaan tetap muncul juga
  • undocumented IPolicyConfig (ganti output device) dan WNF (Focus Assist) bisa rusak pas update Windows. Harus dipasang di balik probe
  • admin UIPI: island gak bisa ngatur window admin, jadi butuh helper elevated lewat Task Scheduler. Path exe harus aman biar gak jadi celah privilege escalation
  • PrtSc Ngambil alih tombol PrtSc dari Snipping Tool butuh izin user (registry), jangan diam-diam
  • tile Border tak terlihat, app UWP, app dengan ukuran minimum, dan app yang restore posisinya sendiri (perlu retry)
  • media Hanya aplikasi yang expose Windows SMTC terlihat. Browser bisa melaporkan nama browser saja; artwork/control/duration bisa tidak tersedia. Tidak memaksa login atau playback. Profil lama tidak dihapus.
  • brightness Tombol brightness laptop sering gak lewat hook, jadi flyout bawaan bisa tetap muncul

Lisensi

  • WinIsland: GPL-3.0. Mole branch windows: GPL-3.0, plus trademark "Mole"
  • Kita port konsep saja: struktur, pilihan API, dan ide. Kode ditulis ulang, daftar path disusun sendiri
  • Jangan pakai nama atau logo Mole, dan jangan ngaku-ngaku afiliasi
  • Lisensi kita bebas (rekomendasi MIT/Apache-2.0) selama gak ada kode yang di-copy
